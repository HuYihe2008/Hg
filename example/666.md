# 明文登录阶段流程文档

## 概述

明文登录阶段使用两个主要域名：
- **as.hypergryph.com** - 鹰角通行证认证服务
- **u8.hypergryph.com** - Unity 用户认证服务

## 关键常量

```python
PASSPORT_APP_CODE = "dd7b852d5f1dd9da"  # 鹰角通行证 APP_CODE
U8_APP_CODE = "4df8f5a7c2ad711b497a"    # Unity U8 APP_CODE
CHANNEL_MASTER_ID = "1"                  # 渠道主ID
```

## 完整登录流程

### 阶段一：鹰角通行证扫码登录 (as.hypergryph.com)

#### 步骤 1.1：获取扫码登录二维码

```
POST https://as.hypergryph.com/general/v1/gen_scan/login
Content-Type: application/json

请求体:
{
  "appCode": "dd7b852d5f1dd9da"
}

响应:
{
  "data": {
    "scanId": "f1a20a2e9d22b105f81381434d19d8c8",
    "scanUrl": "hypergryph://scan_login?scanId=f1a20a2e9d22b105f81381434d19d8c8",
    "enableScanAppList": [...]
  },
  "msg": "OK",
  "status": 0,
  "type": "A"
}
```

**输出**: `scanId`, `scanUrl`

---

#### 步骤 1.2：轮询扫码状态

```
GET https://as.hypergryph.com/general/v1/scan_status?scanId={scanId}

响应状态码:
- status=100: 未扫码
- status=101: 已扫码待确认
- status=0: 扫码成功

成功响应:
{
  "data": {
    "scanCode": "CKCCejPjDK9dhp+LVh2RXWUbRK0W4kXHFSBP4zKqHrLKqe53wpL+5HF70etPBAdSthIKpUhgqwH26j7P79qE7WziLXDber+WhnTd/J6ZI8dZh8ignZrHUHI="
  },
  "msg": "OK",
  "status": 0,
  "type": "A"
}
```

**输出**: `scanCode`

---

#### 步骤 1.3：使用 scanCode 获取 token

```
POST https://as.hypergryph.com/user/auth/v1/token_by_scan_code
Content-Type: application/json

请求体:
{
  "appCode": "dd7b852d5f1dd9da",
  "scanCode": "{scanCode}",
  "from": 1
}

响应:
{
  "data": {
    "token": "gfwJ/Hk2NYoW6fm2SqP7d4Sd",
    "hgId": "1256195874071",
    "deviceToken": "Rs0bUEyMfxGeK840"
  },
  "msg": "OK",
  "status": 0,
  "type": "A"
}
```

**输出**: `token`, `hgId`, `deviceToken`

---

#### 步骤 1.4：OAuth2 鉴权获取 code

```
POST https://as.hypergryph.com/user/oauth2/v2/grant
Content-Type: application/json

请求体:
{
  "deviceToken": "{deviceToken}",
  "type": 0,
  "token": "{token}",
  "appCode": "dd7b852d5f1dd9da"
}

响应:
{
  "data": {
    "uid": "1454556009562",
    "code": "8tSR0WISlGtZqdl38XB0cgAMDJ0qWr9uUssNm63idWJzpQrt6bSbdvuyyqQL6RkywSEzkbr/hlGX7Y51kn3ENClE1kZ7wPIxnBbpo2yzqDBuQMZL6eia0NK4tUwjpKERlfXfuhsqz3XdfVbMITKFXUJxgdxTD0ZYCpGW8Xk7dPeYzznqKw=="
  },
  "msg": "OK",
  "status": 0,
  "type": "A"
}
```

**输出**: `uid` (鹰角通行证UID), `code` (OAuth授权码)

---

#### 步骤 1.5：构造 channelToken

```python
channel_token = json.dumps({
    "type": 1,
    "isSuc": True,
    "code": "{code}"  # 来自步骤1.4的code
}, ensure_ascii=False, separators=(",", ":"))
```

## 流程图

```
┌─────────────────────────────────────────────────────────────┐
│ 阶段一: 鹰角通行证扫码登录                      │
├─────────────────────────────────────────────────────────────┤
│ 1. POST /general/v1/gen_scan/login                          │
│    → 获取 scanId, scanUrl                                    │
│                                                              │
│ 2. GET /general/v1/scan_status?scanId={scanId}              │
│    → 轮询直到获取 scanCode                                    │
│                                                              │
│ 3. POST /user/auth/v1/token_by_scan_code                     │
│    → 获取 token, hgId, deviceToken                           │
│                                                              │
│ 4. POST /user/oauth2/v2/grant                                │
│    → 获取 uid, code                                          │
│                                                              │
│ 5. 构造 channelToken = {"type":1,"isSuc":true,"code":"..."}  │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 阶段二: Unity 用户认证                          │
├─────────────────────────────────────────────────────────────┤
│ 6. POST /u8/user/auth/v2/token_by_channel_token             │
│    → 获取 Unity token, uid (游戏UID)                         │
│                                                              │
│ 7. POST /game/server/v1/server_list                          │
│    → 获取服务器列表                      │
│                                                              │
│ 8. POST /u8/user/auth/v2/grant                               │
│    → 获取 code (grant_code, 用于TCP登录)                     │
│                                                              │
│ 9. POST /game/role/v1/confirm_server (可选)                  │
│    → 确认登录服务器                                           │
└─────────────────────────────────────────────────────────────┘
                              ↓
┌─────────────────────────────────────────────────────────────┐
│ 阶段三: TCP 登录 (加密通信)                                   │
├─────────────────────────────────────────────────────────────┤
│ 10. 连接 TCP 服务器 (host:port)                              │
│ 11. 发送握手包                                               │
│ 12. 发送登录消息 (使用 grant_code)                            │
│ 13. 接收登录响应                                             │
└─────────────────────────────────────────────────────────────┘
```

## 关键数据说明

| 数据 | 来源 | 用途 |
|------|------|------|
| `scanId` | 步骤 1.1 | 轮询扫码状态 |
| `scanCode` | 步骤 1.2 | 换取 token |
| `token` (passport) | 步骤 1.3 | OAuth2 鉴权 |
| `deviceToken` | 步骤 1.3 | OAuth2 鉴权 |
| `code` (OAuth) | 步骤 1.4 | 构造 channelToken |
| `channelToken` | 步骤 1.5 | Unity 鉴权 |
| `token` (Unity) | 步骤 2.1 | 获取服务器列表、Grant |
| `uid` (游戏) | 步骤 2.1 | 游戏用户ID |
| `code` (grant) | 步骤 2.3 | **TCP登录凭证** |
| `host:port` | 步骤 2.2 | TCP服务器地址 |
